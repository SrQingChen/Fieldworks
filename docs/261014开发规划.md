## 任务分解

### T1 删除管道泵 + 通风管
- FWBlocks 移除 PUMP/VENT_PIPE；删 VentPipeBlock/VentPipeBlockEntity；FWBlockEntities 移除 VENT；
  gen_data 移除 pump/vent_pipe 配方、模型、blockstate、贴图、标签、lang；进度 deep_breath(vent_pipe) 改挂 field_coupler。
- 通风管功能（深层氧势回灌 0.01/10s）实际不可感知，按用户判定删除。

### T2 管道三族重构（合并气/液 → 流体管道；新增物品/能量管道）
- PipeBlock：`boolean gas` → `PipeKind {FLUID, ITEM, ENERGY}`；connectTo 按 kind：
  同类管互连；机器连接判定 = 流体(有罐)/物品(有物品槽)/能量(有能量处理器)。
- PipeBlockEntity 保留（仅流体）；新增 ItemPipeBlockEntity（缓冲 ItemStack，PULL 机器输出面/PUSH 输入面/管间水位平衡）
  与 EnergyPipeBlockEntity（缓冲 FE，发电机 OUTPUT/AUTO 面→管→耗电机器 INPUT/AUTO 面，管间平衡）。
- MachineBlockEntity 新增管道侧物品/能量读写口（尊重六面 IO）。
- BER：ItemPipe/EnergyPipe 渲染琥珀色盒/青色脉冲盒（复用 PIPE_CONTENT 管线）；三 BE 类型共用渲染逻辑基类。
- 资产：gen_pipes_v3 三族（流体=蓝、物品=琥珀橙、能量=青 #1E9E96）；gen_assets_v2.pipe_models 三族 multipart+直段物品模型；
  gen_data 配方三族；gas_pipe 全清理（含 QA 哨兵更新）。

### T3 机器 UI 四连修
1. **接线（U7 根因）**：MachineMenu 匿名 ContainerData.set() 为空实现，客户端收到
   ClientboundContainerSetDataPacket 后值被丢弃、get() 永远读客户端 BE 静态值 → 能量/储罐/进度/环境全部"零变化"
   （Jade 走 BE 数据包故正常）。修复：客户端缓存 int[]，set() 写缓存，get() 客户端读缓存/服务端读实时。
2. **左上附属部件重叠（U5）**：FitBadge(66×48 @y2) 与 IO/能量页签(y6/y28) 相交 → 页签下移至 y=58/80 上下分布；
   JEI 排除区同步。
3. **IO 浮窗层级（U6）**：26.1.2 渲染顺序 background→labels→物品槽→前景事件；浮窗画在 extractBackground 必在物品下。
   改为覆写 extractContents（super 之后绘制）→ 位于全部物品之上、光标物品/tooltip 之下。
4. **槽位 1px 偏移（U9）**：gen_atlas_v3 烘焙的玩家背包槽井画在 (slotX,slotY)（18×18）而非 (slotX-1,slotY-1)
   → 视觉右下偏 1px。生成器改 -1 对齐并重跑；qa_gui_layout 增加"烘焙格=真实槽-1"断言。
5. **能量槽风格（U8）**：核对 261012 规划原文——"琥珀 #E8A33D 仅保留能量条"，当前实现即规划体系（青色主+原版浅底+琥珀能量），
   保持不变，交付时向用户答复。

### T4 能量单位 FE/RF/J

  tooltip/能量页签/手册同步；lang 键补充。

### T6 计数配料 + 配方全量重设计
- MachineRecipe.inputs：`List<InputEntry(Ingredient, count)>`；JSON 兼容纯字符串(count=1) 与
  `{"ingredient":"minecraft:iron_ingot","count":16}`；consumeInputs/findRecipe 按数量消耗；
  JEI 槽位旁绘制 ×N 角标；placementInfo 适配。
- gen_data 重设计：12 部件配方全部复合化（铜线圈=铜×6+铁×2 等）、机器组装配方大幅加料
  （如初级机器=钢壳×2+部件×n+铁×16 级别）、未利用素材（carbon_black 等）接入新配方、
  部分原版合成配方丰富（观测设备/人工场件等）；能量/时长同步上调。

### T7 无限水泵（infinite_water_pump）
- 新 Mode.PUMP + spec（ENVIRONMENT 族、内置水电容、能量 40k、0 物品槽、1 罐 8000mB）；
  InfinitePumpBlockEntity extends MachineBlockEntity（独立 BE 类型，复用菜单/屏幕/管道/Jade 生态）。
- 机制：六面 ≥2 面邻水源方块才工作；仅耗电产水入内置罐（管道/相邻机器自动取水）。
- 三档：低 50mB/t@0.8FE/mB、高 150mB/t@1.2FE/mB、无限档按管道实际吞量输出、耗电 = 流量×0.8×2^(流量/250)（指数）。
- GUI：PART 风格布局 + 档位页签（点击循环，C2S 档位包，D_MODE 数据槽同步）；缺水时 UI 提示。
- 配方：前中期复合耗材（钢壳+涡轮叶片+密封法兰×2+铜线圈×4+逻辑电路+铁×16 级别）；手册新条目。
